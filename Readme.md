# 💰 Financial Behavior Analyzer

A full-stack AI-powered expense tracking application that helps users manage daily expenses, analyze spending behavior, and generate intelligent financial insights.

---

## 🚀 Features

- 🔐 User Authentication (Login & Signup)
- 💵 Add Expenses
- ✏️ Edit Expenses
- 🗑 Delete Expenses
- 🔍 Search Expenses
- 📅 Daily Expense Tracking
- 📊 Monthly Analytics
- 🤖 AI Financial Insights
- 🧠 Machine Learning Model Integration
- 🗄 PostgreSQL Database
- ⚡ FastAPI Backend
- ⚛ React + TypeScript Frontend

---

## 🛠 Tech Stack

### Frontend

- Random Forest Classifier

---

## 📊 AI & Analytics

The application provides intelligent financial insights including:

- Today's total spending
- Comparison with yesterday's spending
- Comparison with monthly average
- Highest spending category
- Natural language financial insights

Machine Learning pipeline:

- Data preprocessing
- Feature engineering
- Random Forest Classifier
- Model serialization using Joblib
- FastAPI prediction endpoint

## ⚙ Installation

### Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
