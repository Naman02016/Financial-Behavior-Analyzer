# 💰 Financial Behavior Analyzer

A full-stack AI-powered expense tracking application that helps users manage daily expenses, analyze spending behavior, and generate intelligent financial insights using Analytics and Machine Learning.

---

## 🚀 Features

- 🔐 User Authentication (Login & Signup)
- 💵 Add, Edit & Delete Expenses
- 🔍 Search Expenses
- 📅 Daily Expense Tracking
- 📊 Monthly Analytics Dashboard
- 🤖 AI Financial Insights
- 🧠 Machine Learning Model Integration
- 🗄 PostgreSQL Database
- ⚡ FastAPI REST API
- ⚛ React + TypeScript Frontend

---

## 🛠 Tech Stack

### Frontend

- React
- TypeScript
- Tailwind CSS
- React Router
- Lucide React

### Backend

- FastAPI
- SQLAlchemy
- PostgreSQL
- Pydantic

### AI / Machine Learning

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier
- Joblib

---

## 📊 AI & Analytics

The application provides intelligent financial insights including:

- Today's total spending
- Comparison with yesterday's spending
- Comparison with monthly average
- Highest spending category
- Personalized AI financial insights

### Machine Learning Pipeline

- Data preprocessing
- Feature engineering
- Random Forest model training
- Model serialization using Joblib
- FastAPI prediction endpoint

## ⚙ Installation

### Backend

```bash
cd backend

pip install -r requirements.txt

python -m uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
